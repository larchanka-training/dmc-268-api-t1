AGENTS.md

Примечание: этот документ предназначен только для пользователей и не предназначен для агентов.

Этот проект представляет собой агента для автоматического ревью кода в пул- и мердж-реквестах. Он может запускаться автоматически при открытии или обновлении реквеста, либо вызываться по требованию — командой, кнопкой или упоминанием.

При запуске агент собирает diff между ветками, отфильтровывает нерелевантные или автоматически сгенерированные файлы, разбивает крупные изменения на удобные для обработки части и дополняет их контекстом — например, описанием реквеста и уже существующими комментариями. Этот контекст передаётся через уровень оркестрации языковой модели, которая проверяет код по нескольким направлениям — уязвимости безопасности, логическая корректность, проблемы производительности, безопасность параллелизма и работы с ресурсами, а также читаемость — при этом отсеивая вероятные ложные срабатывания.

Перед публикацией каждая находка сверяется с фактическим diff, чтобы подтвердить, что она указывает на реально изменённую строку; дублирующиеся или малоценные комментарии удаляются. Затем агент публикует сводку ревью, отдельные комментарии к соответствующим строкам (включая исправления, применяемые в один клик, если это возможно) и обновление статуса. Ответы на его комментарии обрабатываются как продолжение диалога, а не как повод для полного повторного ревью.
