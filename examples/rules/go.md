# Правила ревью: Go

Шаблон `.review/rules.md` для сервиса на Go. Скопируйте файл в `.review/rules.md` своего
репозитория и поправьте паттерны под свою раскладку каталогов. Абзацы вроде этого сервис
модели не передаёт: правилом считается только раздел `##` с `pattern:` и нумерованными
проверками. Как писать свои правила — `docs/RULES_GUIDE.md`.

## Go Error Handling

- pattern: `*.go`
- exclude: `*_test.go`

1. Возвращённая ошибка не отбрасывается через `_` без комментария, почему её можно игнорировать
2. Ошибка, передаваемая выше, обёрнута с контекстом: `fmt.Errorf("...: %w", err)`
3. Ошибки сравниваются через `errors.Is` и `errors.As`, а не через `==` или текст
4. `panic` используется только для невозможных состояний при инициализации, а не для ошибок ввода

## Context and Concurrency

- pattern: `*.go`
- exclude: `*_test.go`

1. Функция с вводом-выводом принимает `context.Context` первым аргументом и передаёт его дальше
2. У запущенной горутины есть способ завершиться (`ctx.Done()`, закрытие канала): она не утекает
3. Данные, общие для горутин, защищены мьютексом или передаются через канал
4. `sync.Mutex` и структуры с ним не копируются по значению
5. В цикле не создаётся `time.After`: используются `time.Timer` или `time.Ticker`

## Resources

- pattern: `*.go`
- exclude: `*_test.go`

1. `defer Close()` стоит сразу после проверки ошибки открытия ресурса
2. Тело HTTP-ответа (`resp.Body`) закрывается на всех путях
3. После цикла по `rows.Next()` проверяется `rows.Err()`

## HTTP

- pattern: `*.go`
- exclude: `*_test.go`

1. Исходящие запросы идут через `http.Client` с `Timeout`, а не через `http.DefaultClient`
2. У `http.Server` заданы `ReadHeaderTimeout` и остальные таймауты
3. Обработчик проверяет метод и размер тела запроса (`http.MaxBytesReader`)

## Go Tests

- pattern: `*_test.go`

1. Варианты одного поведения собраны в табличный тест с именами случаев
2. Вспомогательная функция теста вызывает `t.Helper()`
3. Тест не синхронизируется через `time.Sleep`: используются каналы, `sync.WaitGroup` или опрос с таймаутом
