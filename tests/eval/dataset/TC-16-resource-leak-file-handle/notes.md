# TC-16 — утечка ресурса: файл не закрыт на пути ошибки

`open` без `with`: на счастливом пути `close()` есть, на пути исключения — нет.

- `handle-leak-on-error` (correctness, medium, must_find) — строка `open(...)`.
  medium: утечка одного дескриптора на сбой, но в воркере сбои копятся.

`security` запрещена: путь задаёт вызывающий код, а не пользователь.
В эталонном ответе есть лишнее замечание о читаемости (`DictWriter`) — правдоподобный
FP низкой важности: `readability` здесь не запрещена, но и не ожидается.
