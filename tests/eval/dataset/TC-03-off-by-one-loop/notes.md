# TC-03 — off-by-one в границе цикла

Тонкий дефект: функция выглядит правильно, число страниц посчитано верно, но
`range(1, total_pages)` при нумерации с 1 не доходит до последней страницы. Для
списка короче одной страницы функция возвращает пусто.

- `last-page-dropped` (correctness, high, must_find) — строка `for … in range(1, total_pages)`.

`security` запрещена: чистая функция над списком, уязвимости здесь нет.
