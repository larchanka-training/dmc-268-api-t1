# TC-01 — SQL-инъекция

Проверяет, что модель видит инъекцию в сыром SQL: параметр `name` из query
подставляется в `text(f"…")` без связывания.

- `sql-injection` (security, critical, must_find) — строка с f-строкой запроса.
  Ограничение `max_length=100` инъекцию не закрывает: 100 символов на `UNION SELECT`
  хватает.

`readability` запрещена: дифф короткий и чистый, замечание о стиле здесь — шум,
который отвлекает от уязвимости.
