# TC-06 — синхронный вызов в цикле без батчинга

Блокирующий HTTP-вызов в асинхронной функции, по одному на находку. У GitHub есть
пакетная форма — одно ревью со списком комментариев.

- `sync-http-in-loop` (performance, high, must_find) — строка `requests.post(` в цикле.
- `no-timeout` (correctness, medium, nice-to-have) — у вызова нет `timeout`: зависший
  GitHub подвешивает воркер навсегда. Якорь — конец аргументов вызова, ±3 покрывает
  и `json=`, и закрывающую скобку. Второстепенно по сравнению с главным дефектом.

`security` запрещена: токен приходит аргументом, а не из кода.
В эталонном ответе `no-timeout` пропущен — допустимый промах nice-to-have.

Ответ сознательно ставит замечание о тайм-ауте на строку 27 — за пределами окна `±3` от
`requests.post(` (строка 16). По правилу §2 это FP, а необязательное `no-timeout` не найдено,
без FN. Если окно сломается (расширится), пара сложится и снимок в `test_gold_runner.py`
изменится.
