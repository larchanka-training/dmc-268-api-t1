# TC-04 — проверка, затем запись без транзакции

Дефект виден только с контекстом: в диффе широкий контекст (12 строк), чтобы
модель видела `balance()` с отдельной сессией и `top_up()` с `with_for_update()` —
образец правильного обновления в том же классе.

- `check-then-write-race` (correctness, high, must_find) — запись
  `account.balance = current - charge.amount`: устаревшее значение из другой сессии
  без блокировки строки. Модель может указать на чтение `self.balance(...)` или на
  `session.get` — они в окне ±3 от записи не все, поэтому якорь — строка записи,
  итог гонки.

`readability` запрещена: код читается нормально, замечание о стиле — шум.
В эталонном ответе строка указана на две выше (открытие транзакции).
