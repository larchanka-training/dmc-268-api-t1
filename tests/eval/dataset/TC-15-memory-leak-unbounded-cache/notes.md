# TC-15 — утечка памяти: неограниченный кэш

Модульный словарь с ключом по SHA коммита: каждый пуш — новый ключ, вытеснения нет.
Рядом список подписчиков без отписки.

- `unbounded-cache` (performance, high, must_find) — объявление `_rules_cache`. Модель
  может указать и на запись в словарь внутри `load_rules`, но она за окном ±3 от
  объявления; якорь — объявление: дефект в том, что у словаря нет границы, а не в
  конкретной записи.
- `listeners-never-removed` (performance, medium, nice-to-have) — `_listeners.append`.

`security` запрещена: данные приходят из своего же VCS-шлюза.
