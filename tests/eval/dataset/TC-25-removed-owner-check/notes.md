# TC-25 — проверка владельца удалена (якорь на стороне old)

PR заявлен как «архивировать прогоны при удалении проекта» и вместе с новой строкой молча удаляет
проверку `project.owner_id != user.id`. Любой вошедший пользователь теперь удаляет чужой проект — IDOR.

- `owner-check-removed` (security, critical, must_find) — **удалённая** строка 23, `side: old`.
  Дефект — в том, чего больше нет: на стороне new строки с ним нет, поэтому правильный якорь — старая
  сторона. Кейс проверяет, что сопоставление сравнивает сторону и номер строки той же стороны.

`readability` и `performance` запрещены: изменение в три строки, говорить кроме дыры не о чем.

Второе, необязательное нарушение — `archive-delete-not-atomic` (сторона `new`, строка 23:
архивация и удаление без общей транзакции). Ответ сознательно привязывает его к стороне
`old` той же строки — частая ошибка модели рядом с удалёнными строками. По правилу §2 это FP,
а необязательное нарушение остаётся ненайденным, без FN. Если сопоставление перестанет
сравнивать сторону, пара сложится и снимок в `test_gold_runner.py` изменится.
