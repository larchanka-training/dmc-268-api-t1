# TC-05 — N+1 запрос в цикле

Классический N+1: после выборки 100 прогонов на каждый идёт отдельный `count`.

- `n-plus-one` (performance, medium, must_find) — строка с `session.scalar(` в цикле.
  medium, а не high: выдача ограничена сотней, это 101 быстрый запрос, а не
  неограниченный рост.

`security` запрещена: запросы параметризованы, ввода пользователя нет.
