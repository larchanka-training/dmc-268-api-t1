# TC-12 — большой MR

Проверяет **лимиты контекста и честное усечение**: 203 файла, больше 5000 строк диффа (`diff.patch` —
сгенерирован скриптом, ~220 КБ). Пакет контекста по умолчанию — 32 000 токенов ≈ 128 КБ
(`context_max_tokens`, `BYTES_PER_TOKEN = 4`), hunk'и берутся в порядке диффа, не вошедшее уходит в
`omitted`. Порядок файлов — как у git, по пути: `app/api/admin_exports.py` → `app/handlers/…` →
`app/workers/retry.py`.

- `export-path-traversal` — `security/high`, `must_find: true`. Стоит в первом файле диффа, поэтому
  попадает в пакет при любом усечении: Recall на этом кейсе измерим. `name` из query склеивается с
  каталогом выгрузок — `../` читает любой файл процесса. Ручка под `require_admin`, поэтому не
  `critical`.
- `retry-off-by-one` — `correctness/medium`, `must_find: false`. `range(1, attempts)` делает
  `attempts - 1` попыток, а при `attempts=1` — ни одной и сразу `RuntimeError`. Файл последний в
  диффе и при бюджете по умолчанию в пакет **не входит**: требовать находку, которую модель не видела,
  нельзя. Если раннер/конфигурация даст больший бюджет — найденное засчитается TP.

Ожидаемое поведение: модель находит обход каталога, не выдумывает замечаний к файлам, которых не
видела, и в сводке честно говорит, что проверена только часть PR. Эталонный ответ так и делает
(пропуск `retry-off-by-one` допустим) и содержит одно ложное `readability/low` о дублировании
обработчиков — реалистичный шум, не входящий в разметку. Обработчики корректны: дефектов в них нет.
`max_findings: 5` ловит ковровую бомбардировку по однотипным модулям.
