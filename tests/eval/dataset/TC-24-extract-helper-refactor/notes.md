# TC-24 — корректный рефакторинг с выносом функции

Негативный кейс: дублированный расчёт двух частей стоимости вынесен в `_tokens_cost`. Порядок
операций и округление сохранены: каждая часть округляется до `0.0001` отдельно, затем части
складываются — как и раньше. Новый тест фиксирует именно это: 3 токена стоят `0.00006`, каждая
часть округляется вверх до `0.0001`, сумма `0.0002`.

Ловушки:

- «округлять надо сумму, а не части» — поведение до PR было тем же, PR его не меняет;
- «`Decimal(tokens) / 1000` теряет точность» — деление `Decimal` на `int` точное в контексте 28 знаков;
- «приватную функцию стоит покрыть отдельным тестом» — она покрыта через `run_cost`.

`max_findings: 0`, `readability` запрещена.
