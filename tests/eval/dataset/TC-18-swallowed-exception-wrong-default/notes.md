# TC-18 — проглоченное исключение и неверное значение по умолчанию

`except Exception` без лога и с откатом к `UNLIMITED`: недоступный биллинг (или любой
баг внутри `try`) открывает безлимит. Безопасное значение по умолчанию — `FREE_LIMITS`,
которое уже есть в модуле.

- `swallowed-wrong-default` (correctness, high, must_find) — `return UNLIMITED`; строка
  `except Exception:` выше на одну, в окне.

`performance` запрещена: дефект о поведении, не о скорости.
В эталонном ответе замечание о неиспользуемом `logger` — правдоподобный FP: формально
верно, но это следствие главного дефекта, а не самостоятельная находка (в разметке его
нет).
