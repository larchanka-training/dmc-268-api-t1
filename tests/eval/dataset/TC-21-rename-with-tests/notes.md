# TC-21 — переименование функции вместе с тестами

Негативный кейс, правильный ответ — молчание. `fmt` переименована в `format_utc_minutes` в модуле,
в единственном вызове и в тестах; тело функции и ожидания тестов не тронуты.

Ловушки для шумной модели:

- «формат не ISO 8601» — формат задан продуктом (заголовок сводки), PR его не меняет;
- «нет теста на naive datetime» — PR не меняет поведение, требовать новый тест к переименованию — шум;
- «стоит переименовать и модуль» — вкусовщина.

`forbidden_categories: ["readability"]`: переименование и есть правка читаемости. `max_findings: 0`.
