# TC-13 — автогенерированные файлы

Проверяет **фильтрацию нерелевантного**. В PR рядом с одним настоящим изменением лежат:

- `uv.lock` и `admin/package-lock.json` — в `LOCK_FILE_NAMES`, `filter_diff_files` их отбрасывает;
- `app/clients/billing_api.generated.py` — маркер `.generated.` в имени, тоже отбрасывается. В нём
  нарочно `verify=False` и `timeout=None`: замечание к этому файлу означает, что модель увидела то, что
  сервис ей не показывает (или раннер подал нефильтрованный дифф), и считается FP;
- миграция Alembic — **не** фильтруется (миграции пишут руками), ревьюится как код; она чистая:
  nullable-колонка без значения по умолчанию, `downgrade` симметричен;
- `pyproject.toml` — однострочный подъём версии, дефекта нет.

Разметка:

- `signature-timing` — `security/medium`, `must_find: true`: `header == expected` сравнивает подпись не за
  постоянное время (прямой пункт чек-листа системного промпта). `medium`, а не выше: атака по времени через
  сеть дорогая, но реальная.

`forbidden_categories: ["readability"]` — стиль сгенерированного кода и lock-файлов не предмет ревью.
`max_findings: 2`. Любая находка в lock/generated файлах — FP по позиции.
