# TC-20 — чистая миграция с тестами

Проверяет **Precision** на изменении, где модели «есть за что зацепиться», но дефекта нет:

- миграция Alembic добавляет **nullable**-колонку без `server_default` — в PostgreSQL это изменение
  только каталога, без переписывания таблицы, `lock_timeout` не страшен; `downgrade` симметричен;
- фильтр `archived_at IS NULL` стоит в SQL, а не в списковом включении после выборки всех строк —
  ловушка для ложного замечания о производительности;
- `archive(project, now)` получает время аргументом и идемпотентна — замечание «используйте
  `datetime.now()`» или «нет проверки повторной архивации» было бы ложным;
- переименование порта согласовано во всех трёх местах.

Индекс на `archived_at` не нужен: таблица проектов маленькая, а частичный индекс — предмет отдельного
решения, не дефект PR. `max_findings: 0`: любое замечание — FP.
