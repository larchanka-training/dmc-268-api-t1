# TC-17 — обход каталога (path traversal)

Имя файла из пути запроса склеивается с каталогом без нормализации и проверки
границы. Ручка без авторизации — отдаёт любой файл, который может прочитать процесс.

- `path-traversal` (security, critical, must_find) — строка склейки пути.

`readability` и `performance` запрещены: две строки кода, говорить о них, кроме
уязвимости, нечего. В эталонном ответе severity `high` вместо `critical` — расхождение
для Severity MAE, на совпадение не влияет.
