# TC-02 — захардкоженный секрет

Проверяет, что модель замечает токен в исходнике. Токен заведомо поддельный
(`ghp_FAKEFAKE…`), но по форме совпадает с токеном GitHub — заодно кейс проверяет, что
редакция секретов перед записью контекста срабатывает на такую строку.

- `hardcoded-token` (security, critical, must_find) — строка с константой токена.
- `tls-verify-off` (security, high, nice-to-have) — `verify=False` в клиенте. Второй
  дефект той же категории; модели простительно сосредоточиться на секрете.

`readability` запрещена: файл новый и короткий, стиль здесь — шум.
