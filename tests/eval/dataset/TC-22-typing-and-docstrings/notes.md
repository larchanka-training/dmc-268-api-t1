# TC-22 — аннотации типов и докстринги

Негативный кейс: PR только добавляет типы и докстринги, логика байт в байт прежняя.

Ловушки:

- `-(-total // size)` — корректное деление с округлением вверх для неотрицательных `total`, не баг;
- срез `Sequence` возвращает `Sequence` — аннотация `list[Sequence[T]]` верна;
- синтаксис `def chunked[T]` — PEP 695, Python 3.12+, проект на 3.14;
- «сообщение исключения не по-русски» — строка не тронута PR.

`max_findings: 0`, `readability` запрещена: документирование — улучшение читаемости.
