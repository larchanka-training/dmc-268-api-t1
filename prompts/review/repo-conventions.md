# Промпт: конвенции репозитория

Выполняется до генерации замечаний. Результат — вход для всех остальных шагов: изменение
оценивается против конвенций этого проекта.

---

Изучи проверяемый репозиторий и верни объект:

```json
{
  "files": [{ "path": "...", "relevance": "почему файл важен для этого изменения" }],
  "key_patterns": ["конвенция, наблюдаемая в коде, с указанием места"],
  "recommendations": ["проверка-напоминание к текущему диффу"]
}
```

Требования:

- `key_patterns` — то, что видно в коде, а не общие слова. «Решения — чистые функции в
  `app/domain`, время приходит аргументом» — конвенция. «Код должен быть читаемым» — нет.
- Локальная конвенция важнее общепринятой практики. Если проект делает иначе, чем принято, и это
  видно в нескольких местах — это правило проекта, а не дефект.
- `recommendations` — проверки под конкретный дифф, а не универсальный чеклист.

## Пример для `dmc-268-api-t1`

```json
{
  "files": [
    { "path": "app/domain/lifecycle.py", "relevance": "таблица переходов прогона ревью" },
    { "path": "app/infrastructure/db/repositories.py", "relevance": "адаптеры, сверяющиеся с доменом перед записью" }
  ],
  "key_patterns": [
    "Решение принимает функция над данными в app/domain; I/O, часы и случайность передаются аргументами",
    "Адаптер только переводит данные; единственное ветвление — вызов функции домена, и оно помечено комментарием",
    "Порты объявлены как typing.Protocol в app/application/ports; связывание с адаптером только в app/infrastructure/container.py",
    "Схему меняет только ревизия Alembic; приложение при старте ничего не создаёт",
    "Каждая функция домена имеет тест без базы; тесты с PostgreSQL помечены integration и requires_db",
    "Направление зависимостей проверяется import-linter, а не ревью"
  ],
  "recommendations": [
    "Изменение модели пришло вместе с миграцией и с обратимым downgrade",
    "Новый порт оправдан вторым адаптером или границей слоя",
    "Новая функция домена имеет тест, который идёт без TEST_DATABASE_URL",
    "Значение enum добавлено отдельной миграцией через ALTER TYPE"
  ]
}
```
