## ADDED Requirements

### Requirement: Стенд передаёт реквизиты GitHub App

Развёртывание SHALL передавать контейнерам `api` и `worker` идентификатор и приватный ключ GitHub App из настроек репозитория: идентификатор — из переменной, ключ — из секрета. Ключ SHALL NOT храниться в коммитах и SHALL NOT печататься в журнале развёртывания.

#### Scenario: Вебхук на стенде

- **WHEN** на стенд пришёл подписанный вебхук `pull_request` зарегистрированного репозитория
- **THEN** API получает метаданные PR через GitHub App, а не отвечает `502` из-за пустых реквизитов

#### Scenario: Ключ в журнале

- **WHEN** выполняется развёртывание
- **THEN** приватный ключ GitHub App не появляется в журнале job'а
