# Spec Delta

## ADDED Requirements

### Requirement: Прогон хранит покрытие

Прогон SHALL хранить причину неполного покрытия, перечень путей непроверенных файлов и перечень путей файлов, чей hunk больше предела контекста. Прогоны без записанной причины SHALL читаться как прогоны с полным покрытием.

#### Scenario: Прогон до появления покрытия

- **WHEN** читается прогон, созданный до введения покрытия
- **THEN** его покрытие полное, перечни путей пусты
