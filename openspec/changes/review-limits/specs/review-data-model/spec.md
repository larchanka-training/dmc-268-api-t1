# Spec Delta

## ADDED Requirements

### Requirement: Прогон хранит покрытие

Прогон SHALL хранить причину неполного покрытия, перечень путей непроверенных файлов, перечень путей файлов, чей hunk больше бюджета диффа, перечень путей файлов, чьё правило не влезло в долю правил, решение поставить добор и номер в цепочке добора (0 — не добор). Прогоны без записанной причины SHALL читаться как прогоны с полным покрытием, без добора и с номером 0.

#### Scenario: Прогон до появления покрытия

- **WHEN** читается прогон, созданный до введения покрытия
- **THEN** его покрытие полное, перечни путей пусты, добора нет, номер в цепочке 0
