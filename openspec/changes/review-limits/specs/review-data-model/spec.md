# Spec Delta

## ADDED Requirements

### Requirement: Прогон хранит покрытие по файлам

Прогон SHALL хранить покрытие (`complete`, `partial`, `none`) и причину неполноты, а для каждого файла области — его статус покрытия. Прогоны без записанного покрытия SHALL читаться как `complete`.

#### Scenario: Прогон до появления покрытия

- **WHEN** читается прогон, созданный до введения покрытия
- **THEN** его покрытие — `complete`, записей по файлам нет

### Requirement: Репозиторий хранит инсталляцию провайдера

Репозиторий SHALL хранить `installation_id` провайдера; приём вебхука SHALL записывать его из payload, если он отличается от сохранённого. Пустое значение SHALL допускаться до первого вебхука.

#### Scenario: Первый вебхук после миграции

- **WHEN** у репозитория `installation_id` пуст, и приходит вебхук
- **THEN** у репозитория записан `installation_id` из payload
