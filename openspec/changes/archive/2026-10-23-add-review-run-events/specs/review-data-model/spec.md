# Spec Delta

## ADDED Requirements

### Requirement: Сбой фиксирует этап

При переходе прогона ревью в состояние failed система SHALL сохранять этап, на котором прогон находился в момент сбоя: building context, analysing или publishing. Для прогона, упавшего до начала обработки (из queued), и для прогона в любом состоянии, кроме failed, этап сбоя SHALL отсутствовать.

#### Scenario: Сбой фиксирует этап

- **WHEN** прогон ревью переходит в failed из состояния analysing
- **THEN** запись содержит этап сбоя analysing

#### Scenario: Сбой до начала обработки не имеет этапа

- **WHEN** прогон ревью переходит в failed из состояния queued
- **THEN** этап сбоя в записи отсутствует

#### Scenario: Зависший прогон сохраняет этап, на котором остановился

- **WHEN** сборщик зависших прогонов переводит в failed прогон, остановившийся в publishing
- **THEN** запись содержит этап сбоя publishing
