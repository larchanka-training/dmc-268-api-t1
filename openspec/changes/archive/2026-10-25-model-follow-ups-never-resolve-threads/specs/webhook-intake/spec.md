## REMOVED Requirements

### Requirement: Инкрементальный дифф тредов ограничен тем же лимитом

**Reason**: Инкрементальный дифф `prev_head..head` нужен был только для решения, закрывать ли тред критичного замечания по ответу модели. Бот больше не закрывает треды (#73), и этот дифф не запрашивается.

**Migration**: Лимит `DIFF_MAX_BYTES` для диффа прогона — «Лимит размера диффа в воркере», без изменений; закрытие треда — «Ответ модели не закрывает тред» в `review-pipeline`.
