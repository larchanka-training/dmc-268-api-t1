## Why

Экран «Подключить репозиторий» в кабинете работает только на моках: в контракте нет ни списка доступных репозиториев, ни операции подключения. По правилу «контракт первым» запланированная ручка заводится заглушкой `501 NOT_IMPLEMENTED` с полными схемами, чтобы кабинет типизировал мок по контракту. Форма — вариант A решения 3 из dmc-268-ui-t1#37; реализация — #41.

## What Changes

- `GET /api/v1/repositories/available` — заглушка: схема списка репозиториев установки GitHub App с отметкой `already_connected`, ответ `501`.
- `POST /api/v1/repositories` — заглушка: тело `{provider, providerId}`, ответ `201` с `RepositoryResponse` в схеме, сейчас `501`. `Origin`, сессия и тело проверяются как у реализованной ручки.
- Будущие ошибки (нет прав admin, репозиторий уже подключён) описаны текстом операции; коды в каталог добавит реализация.

## Impact

- Код: `app/api/repositories.py`.
- Контракт: `docs/openapi/openapi.json` — две новые операции и три схемы, существующие не меняются.
- Тесты: `tests/test_problem_details.py`.
