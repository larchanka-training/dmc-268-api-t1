## ADDED Requirements

### Requirement: Описание PR обрезается по доле, а не выпадает

Описание PR, не помещающееся целиком в остаток доли контекста PR, SHALL входить в пакет началом, обрезанным до этого остатка, с отметкой, что оно обрезано.
Описание SHALL выпадать в `omitted` только тогда, когда в остаток доли не помещается ни одного его символа.

#### Scenario: Длинное описание

- **WHEN** описание PR вдвое больше доли контекста PR
- **THEN** пакет содержит блок описания с его началом и отметкой об обрезке, а в `omitted` описание не перечислено

#### Scenario: Короткое описание

- **WHEN** описание PR помещается в долю целиком
- **THEN** пакет содержит описание целиком, без отметки об обрезке
