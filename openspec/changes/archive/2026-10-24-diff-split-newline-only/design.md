## Context

Обе функции разбора — чистые функции домена над строкой. Других вызовов `splitlines()` над диффом, кодом или правилами в `app/` нет.

## Decisions

- **`text.removesuffix("\n").split("\n")` и `line.removesuffix("\r")` у каждой строки.** Так строки совпадают с теми, что видят git и GitHub. Завершающий `\n` не даёт лишней пустой строки — как у `splitlines()`. `\r` перед `\n` `splitlines()` отбрасывала; отбрасываем и мы, иначе разбор CRLF-диффа и CRLF-правил поменялся бы (текст hunk'а, имена правил). `\r` внутри строки не трогаем: для git это содержимое.
- **Без общего помощника.** Правило — одно выражение в двух модулях, у которых нет общего модуля, кроме сущностей; помощник ради двух строк — лишняя связь.

## Risks / Trade-offs

- Дифф, где строки разделены одиночным `\r` (старый Mac), раньше делился, теперь — одна строка. Git такой дифф не выдаёт.
