## MODIFIED Requirements

### Requirement: Тип по имени родителя — только для метода

Определение-тип SHALL добавляться в AST-окружение по имени родителя только для изменённого метода — так находится тип ресивера метода Go — и только если сам метод не лежит внутри выбранного по диапазону типа с этим именем. Вложенные функция, класс или интерфейс SHALL NOT добавлять тип с именем охватывающего определения.

#### Scenario: Вложенная функция при слиянии объявлений TS

- **WHEN** в файле есть `interface Money` и `function Money`, и изменена строка вложенной в неё функции `round`
- **THEN** AST-окружение содержит `function Money` и `round`, но не `interface Money`

#### Scenario: Метод Go тянет тип ресивера

- **WHEN** изменена строка метода `func (r *Repo) Save()`, объявленного вне `type Repo struct`
- **THEN** AST-окружение содержит метод и тип `Repo`

#### Scenario: Метод класса не тянет одноимённый тип

- **WHEN** в файле есть `interface Money` и `class Money`, и изменена строка метода `add` этого класса
- **THEN** AST-окружение содержит `class Money` и `add`, но не `interface Money`

#### Scenario: Метод вложенного класса не тянет модульный

- **WHEN** в файле есть модульный `class Local` и `class Local` внутри функции `build`, и изменена строка метода вложенного класса
- **THEN** AST-окружение содержит `build`, вложенный `Local` и метод, но не модульный `Local`

## ADDED Requirements

### Requirement: Функции объектных литералов и сигнатуры TS — определения

Функция в значении свойства объектного литерала JS/TS SHALL быть определением с именем свойства, как функция в поле класса или в переменной. Перегрузка и `declare function` TypeScript SHALL быть определениями-функциями с сигнатурой без хвостового `;`.

#### Scenario: Правка внутри метода объектного литерала

- **WHEN** изменена строка внутри `list: async (req) => {…}` в `export const routes = {…}`
- **THEN** AST-окружение содержит функцию `list` с сигнатурой `list: async (req) =>`

#### Scenario: Перегрузки и declare function

- **WHEN** в файле `.ts` две перегрузки `function parse(…): number;`, реализация и `declare function emit(event: string): void;`
- **THEN** контур файла содержит все четыре функции, у сигнатур нет хвостового `;`
