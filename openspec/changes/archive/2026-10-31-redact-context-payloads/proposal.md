## Why

Пакет контекста прогона хранит дословно код из PR, и всё, что автор по ошибке закоммитил — приватные ключи, токены GitHub, ключи AWS и моделей, — лежит в `context_payloads` открытым текстом (#28). Пакет из базы никто не читает: модели уходит собранный в памяти контекст. Требование о переиспользовании пакета по дайджесту никогда не было реализовано: дайджест считается от уже собранного контекста, и найти «тот же» пакет без сборки нельзя.

## What Changes

- Запись пакета в базу заменяет известные формы секретов меткой `<секрет скрыт>` (`redact_secrets`, `app/domain/secret_redaction.py`) во всех строках тела. Модели пакет уходит как есть: ревью должно увидеть зашитый секрет и указать на него.
- Требование о переиспользовании пакета и сценарий «Идентичный контекст распознаётся» убраны; `find_by_digest` удалён из порта, адаптера и фейка, индекс `ix_context_payloads_digest` — миграцией. `content_sha256` и id блоков недоверенных данных считаются по телу с метками: по исходным слабый пароль подбирался бы офлайн.
- Старые пакеты удаляются миграцией: legacy не держим, данные учебного стенда.

## Capabilities

### Modified Capabilities

- `review-data-model`: REMOVED «Хранение пакетов контекста» (сценарий переиспользования MODIFIED не удалить), ADDED взамен «Хранение пакетов контекста без секретов».

## Impact

- Код: `app/domain/secret_redaction.py`, `retag` в `app/domain/untrusted.py`, дайджест в `app/application/context_assembly.py`, `SqlAlchemyContextPayloadRepo.add`, порт `ContextPayloadRepo`, фейк.
- Окно деплоя: миграция идёт раньше замены воркера, и старый воркер до остановки пишет пакеты без редакции. Риск принят.
- База: миграция `0015` — `DELETE FROM context_payloads`, удаление индекса по дайджесту.
- API и контракт не меняются.
