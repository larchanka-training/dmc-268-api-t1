## ADDED Requirements

### Requirement: Хранение пакетов контекста без секретов

Система SHALL сохранять контекст, собранный для прогона ревью, — материал, отправляемый модели, — фиксируя, к какому прогону он относится, какие файлы охватывает, какие уровни контекста включает, его размер в токенах и дайджест содержимого.

Сохраняемое тело SHALL NOT содержать секретов: известные формы (ключи, токены с префиксом, JWT, пароли в URL, секреты по имени или схеме авторизации) SHALL заменяться меткой, дайджест — считаться по телу с метками. Модели пакет SHALL уходить без замены.

#### Scenario: Собранный контекст сохраняется вместе с прогоном

- **WHEN** сборка контекста для прогона ревью завершена
- **THEN** для этого прогона сохраняется запись пакета контекста со списком файлов, уровнями, числом токенов и дайджестом содержимого

#### Scenario: Секрет из диффа не сохраняется

- **WHEN** в диффе PR есть токен GitHub
- **THEN** модель получает дифф с токеном, а в сохранённом пакете на его месте метка

#### Scenario: Дайджест не выдаёт секрет

- **WHEN** в диффе PR есть пароль в URL
- **THEN** дайджест пакета и id блоков в сохранённом теле посчитаны по тексту с меткой

#### Scenario: Слишком большой контекст сохраняется частями

- **WHEN** собранный контекст превышает бюджет контекста модели и разбивается на части
- **THEN** каждая часть сохраняется отдельной записью пакета, привязанной к тому же прогону и упорядоченной в его рамках

## REMOVED Requirements

### Requirement: Хранение пакетов контекста

**Reason**: переиспользования пакета по дайджесту нет и не было — дайджест считается от уже собранного контекста; сценарий «Идентичный контекст распознаётся» MODIFIED не удалить.

**Migration**: заменено требованием «Хранение пакетов контекста без секретов» в этой же возможности.
