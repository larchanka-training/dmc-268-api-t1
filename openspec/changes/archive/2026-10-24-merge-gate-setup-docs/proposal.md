## Why

Merge gate держится на обязательной проверке `dmc-268-ai-review`. Если сделать её обязательной только по имени, проверку закрывает check run с тем же именем от любого workflow с `checks: write` и commit status от любого, у кого есть право записи в репозиторий. Автор PR обходит gate одним шагом в своём workflow. README об этом молчит и не говорит, как привязать проверку к нашему App.

## What Changes

- В `README.md` — раздел «Merge gate»: какие выводы ставит бот, почему проверку делают обязательной с источником — нашим App, путь в интерфейсе rulesets и команда `gh api` с `integration_id`.
- Оговорки: App появляется среди источников только после своего check run в репозитории; `neutral` и `skipped` проходят обязательную проверку, `failure` блокирует.

## Impact

- `README.md`. Код, контракт API и поведение сервиса не меняются.
