## ADDED Requirements

### Requirement: Пересчёт merge gate только по завершённому ревью head

Пересчёт merge gate по вебхуку закрытия треда SHALL выставлять check run, только если последний прогон на head-коммите PR - `completed`. Если прогона на head нет, или последний идёт, упал или отменён, check run SHALL NOT выставляться: `success` непроверенному коммиту не даётся, gate выставит прогон, который его проверит.

#### Scenario: Тред закрыт, пока ревью нового head идёт

- **WHEN** после push ревью нового head-коммита ещё идёт, и приходит вебхук закрытия треда
- **THEN** check run на новый head не выставляется

#### Scenario: Ревью после смены целевой ветки упало

- **WHEN** последний прогон на head - `failed` (ревью нового диффа), а прежний `completed` был на старой базе, и закрыт тред
- **THEN** check run не выставляется: блокировка смены ветки остаётся

### Requirement: Отменённый прогон не выставляет merge gate

Прогон перед выставлением check run SHALL перечитать свой статус; если его отменили (`cancelled`) - сменой целевой ветки во время работы, - check run SHALL NOT выставляться.

#### Scenario: Ветку сменили во время публикации

- **WHEN** прогон опубликовал ревью, а в базе он уже `cancelled`
- **THEN** check run этим прогоном не выставляется
