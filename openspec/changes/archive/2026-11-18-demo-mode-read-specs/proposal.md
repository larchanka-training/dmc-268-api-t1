## Why

Change `demo-mode` (архив `2026-11-17-demo-mode`) разрешил в демо-режиме читающий запрос (`GET`) без сессии: он обслуживается как запрос демо-пользователя. Исключение попало в `user-auth`, но `review-rest-api` по-прежнему безусловно требует сессию: требование «Ручки чтения требуют сессию» и сценарии «`GET …` без сессии → `401`» в демо-режиме неверны (замечание ревью #432). Поведение кода не меняется — спека догоняет код.

## What Changes

- «Ручки чтения требуют сессию»: оговорка «кроме `GET` в демо-режиме (`demo-mode`)» и сценарий чтения без сессии в демо-режиме.
- Сценарии «без сессии → `401`» у ручек чтения (дифф, шаги, списки репозиториев и прогонов, один репозиторий, настройки, статус правил, поток событий, аналитика, проверка параметров списка прогонов) — с условием «демо-режим выключен».
- Настройки: сценарий «Без сессии» разделён — `PUT` без сессии отвечает `401` всегда, `GET` — при выключенном демо-режиме.
- Общий поток событий: сценарий — в демо-режиме поток без сессии открывается для демо-пользователя, и перепроверка сессии его не закрывает.
