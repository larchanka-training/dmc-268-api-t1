## MODIFIED Requirements

### Requirement: Текущий пользователь

`GET /api/v1/auth/me` SHALL возвращать профиль пользователя текущей сессии: id пользователя сервиса, провайдер, логин, имя и аватар. Без действительной сессии ответ SHALL быть `401`.

#### Scenario: Вошедший пользователь

- **WHEN** запрос с действительной cookie сессии
- **THEN** ответ — `200` с логином и аватаром пользователя

#### Scenario: Id для оплаты

- **WHEN** вошедший пользователь открывает кабинет
- **THEN** ответ `GET /api/v1/auth/me` содержит `id` — тот же, что кнопка оплаты передаёт Stripe в `client-reference-id`
