# Design: публичный репозиторий без явного права не виден

## Decisions

### D1. Публичность не даёт видимости

Change `repository-visibility-private` показывал публичный репозиторий всем вошедшим; с `repositories-via-user-token` видимость — ответ GitHub по `/user/installations…`, то есть только репозитории с явной ролью (read и выше), и публичный репозиторий без роли не виден ни в списке, ни в потоке `GET /events` — это сознательное сужение по правилу dmc-268-ui-t1#43 («доступ на GitHub, любая роль»): кабинет показывает команде её репозитории, а не каталог всего публичного, куда установлено приложение.
