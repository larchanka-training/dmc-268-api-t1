## ADDED Requirements

### Requirement: Настройки ревью хранятся в записи репозитория

Запись репозитория SHALL хранить настройки ревью: признак автоматического ревью, список glob-паттернов целевых веток и порог важности merge gate из значений важности замечания. У записи, созданной без явных значений, SHALL быть `auto_review_enabled = true`, пустой список паттернов и порог `critical`. Настройки SHALL NOT сбрасываться выключением и повторным включением репозитория.

#### Scenario: Запись без настроек

- **WHEN** запись репозитория вставляется без значений настроек (например, старой версией API в окне деплоя)
- **THEN** у неё `auto_review_enabled = true`, пустой список паттернов и порог `critical`

#### Scenario: Существующие записи после миграции

- **WHEN** миграция применяется к базе с зарегистрированными репозиториями
- **THEN** у каждого пустой список паттернов и порог `critical`, `auto_review_enabled` не меняется

#### Scenario: Повторное включение сохраняет настройки

- **WHEN** у репозитория сохранены `auto_review_enabled = false`, `min_severity = high` и `branch_filter = ["main"]`, его выключают и снова включают
- **THEN** настройки остаются прежними: `auto_review_enabled` остаётся `false`, включение задаёт только `connected_at`

#### Scenario: Откат миграции

- **WHEN** миграция настроек откатывается
- **THEN** колонки списка паттернов и порога удаляются, у `auto_review_enabled` снова нет умолчания базы, остальные данные репозиториев целы
