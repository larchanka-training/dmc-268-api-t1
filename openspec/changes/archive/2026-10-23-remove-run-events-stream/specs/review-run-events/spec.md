## REMOVED Requirements

### Requirement: Поток событий статуса прогона

**Reason**: Поток одного прогона удалён: экран прогона перешёл на общий поток `GET /api/v1/events`, клиентов у старого пути нет (задача #103).

**Migration**: События прогона приходят в `GET /api/v1/events` типами `run.*` с данными строки списка; клиент отбирает свой прогон по `id`, снимок берёт из `GET /api/v1/reviews/{review_run_id}`.
