## Context

Код воркера пришёл в #36: `python -m app.worker` из того же образа, что и API,
общие настройки через `load_settings()`. Локально он уже поднимается в
`docker-compose.yml`, на стенде его не было. Стенд описан в `infra/main.tf`
(Terraform, docker-провайдер) и выкатывается `deploy.yml`.

## Decisions

### Контейнер воркера повторяет API

`dmc268-worker` создаётся из `docker_image.api` с другой командой, с теми же
ограничениями (файловая система только для чтения, без capabilities,
512 МБ) и тем же `depends_on` на `migrate`. Блока `ports` нет: воркер говорит
со стеком только через очередь и базу.

Окружение то же, что у API, включая `GITHUB_WEBHOOK_SECRET`. Воркеру секрет
не нужен, но настройки общие, и без него `load_settings()` падает.
Рассмотренная альтернатива — разделить настройки API и воркера. Отклонена:
это правка кода #36 ради одной переменной окружения.

### Готовность брокера не ждём

`depends_on` у docker-провайдера задаёт порядок создания, а не готовность.
Воркер, поднявшийся раньше брокера, падает на подключении, и
`restart = "unless-stopped"` поднимает его снова. Отдельного ожидания, как у
`migrate`, не делаем: рестарт даёт тот же результат без лишнего кода.

### Живость воркера — по счётчику рестартов

HTTP у воркера нет, поэтому `/health`-подобная проверка невозможна.
Состояния «запущен» мало: падающий на старте контейнер Docker перезапускает,
и в момент проверки он снова запущен. Деплой дважды с интервалом 10 секунд
читает `State.Running` и `RestartCount`. Воркер считается живым, если он
запущен и счётчик за интервал не вырос. На это даётся до минуты, поэтому
рестарты в начале, пока брокер не готов, не роняют деплой.

Рассмотренная альтернатива — healthcheck в контейнере через файл-пульс
воркера. Отклонена: нужна правка кода воркера, а на файловой системе только
для чтения — ещё и tmpfs под пульс.

## Risks / Trade-offs

- Воркер, который запущен, но завис в цикле обработки, проверку проходит.
  Ловить такое без пульса из кода воркера нечем; это задача для мониторинга
  очереди, а не для деплоя.
