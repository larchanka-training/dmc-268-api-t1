## ADDED Requirements

### Requirement: Миграция совместима с работающей версией кода

Миграция SHALL быть совместима с версией кода, которая работает на стенде до выката: развёртывание применяет её раньше, чем новый код заменяет старый. Изменение схемы, которое работающий код не переживёт (удаление или переименование используемой колонки, `NOT NULL` без значения по умолчанию, смена типа), SHALL выкатываться в два развёртывания: сначала добавление (expand), затем удаление старого (contract).

#### Scenario: Удаление колонки

- **WHEN** изменение убирает колонку, которую читает работающий код
- **THEN** первое развёртывание выкатывает код без обращений к ней, и только следующее — миграцию, которая её удаляет

#### Scenario: Новая обязательная колонка

- **WHEN** изменение добавляет колонку, которую новый код заполняет всегда
- **THEN** миграция первого развёртывания добавляет её nullable или со значением по умолчанию, и старый код продолжает вставлять строки
