# Proposal

## Why

Шаг `image` в CI и тот же gate в деплое падают на trivy: CVE-2026-109518 (HIGH) в `apt` и
`libapt-pkg7.0` 3.0.3 из базового `python:3.14-slim` (#365). Debian выпустил исправление 3.0.4,
но официальный образ Python пересобирают с опозданием. Пока его не пересобрали, не проходит ни
один пул-реквест и ни один деплой.

## What Changes

- Рантайм-этап `Dockerfile`: `apt-get install --only-upgrade apt` из репозитория Debian, списки
  пакетов удаляются в том же слое. Версию не закрепляем (`# hadolint ignore=DL3008`): закреплённая
  пропадает из репозитория со следующим выпуском. Когда базовый образ догонит, шаг ничего не меняет.

**Не входит:** `apt-get upgrade` всех пакетов ОС — исправляем ту находку, которая роняет gate;
отказ от `python:*-slim` как базы.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

Нет.

`skip_specs: true`: наблюдаемое поведение сервиса не меняется — команды образа, ручки, прогон
ревью те же. Меняется только содержимое рантайм-образа.

## Impact

- `Dockerfile`.
- Сборка образа ходит в репозиторий Debian (`apt-get update`); без сети к нему сборка падает.
