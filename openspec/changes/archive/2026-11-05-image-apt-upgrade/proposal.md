# Proposal

## Why

Job `image` в CI падает на всех бэкендовых PR: trivy находит CVE-2026-109518 (HIGH) в `apt` 3.0.3 базового образа `python:3.14-slim`. Исправление, `apt` 3.0.4, в репозитории Debian уже есть, а сам `python:3.14-slim` собран 2026-10-28 и ещё не пересобран. Develop был зелёным, Dockerfile не менялся: CVE опубликована после. Деплой develop упал бы на том же trivy. Задача #361.

## What Changes

- Runtime-стадия Dockerfile называется `runtime` и обновляет пакеты базового образа: `apt-get update && apt-get upgrade -y`, затем списки пакетов удаляются.
- Деплой передаёт `APT_REFRESH` с датой сборки. Она сбрасывает кэш GHA этого слоя раз в сутки: из кэша слой вернул бы пакеты на момент первой сборки. Сбрасывать на каждой сборке нельзя: digest коммита без правок кода сейчас не меняется, и api с worker не пересоздаются.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

Нет.

`skip_specs: true`: меняется сборка образа, а не поведение сервиса.

## Impact

- `Dockerfile`, `.github/workflows/deploy.yml`.
- Первый деплой каждого дня собирает runtime-стадию заново, digest меняется, и api с worker пересоздаются, даже если код не менялся. Остальные деплои дня берут слой из кэша, как раньше.
