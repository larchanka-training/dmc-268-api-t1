## MODIFIED Requirements

### Requirement: Фильтрация шума в диффе

Перед ревью из разобранного воркером диффа SHALL отфильтровываться файлы, не подлежащие ревью: lock-файлы, минифицированные, сгенерированные, собранные бандлы, бинарные и вендорные (перечни — в сценариях). Обычные исходники и миграции SHALL проходить фильтр неизменёнными. Правила SHALL жить в одном месте — чистой функции домена `filter_diff_files`, без дублирования в адаптерах.

#### Scenario: Перечень lock-файлов

- **WHEN** дифф содержит любой из файлов `package-lock.json`, `npm-shrinkwrap.json`, `pnpm-lock.yaml`, `yarn.lock`, `poetry.lock`, `uv.lock`, `Pipfile.lock`, `composer.lock`, `Cargo.lock`, `Gemfile.lock`, `go.sum` или другой lock-файл
- **THEN** этот файл исключается из результата фильтрации

#### Scenario: Lock-файл отфильтрован

- **WHEN** дифф содержит `package-lock.json` или иной lock-файл
- **THEN** этот файл исключается из результата фильтрации

#### Scenario: Минифицированный и сгенерированный код отфильтрован

- **WHEN** дифф содержит `*.min.js`, `*.min.css`, `*.generated.*` или `*.pb.go`
- **THEN** эти файлы исключаются из результата фильтрации

#### Scenario: Собранные бандлы отфильтрованы

- **WHEN** дифф содержит файл внутри каталога `dist/` на любой глубине, `*.bundle.js`, `*.bundle.css` или source map `*.js.map`, `*.css.map`
- **THEN** эти файлы исключаются из результата фильтрации, а `src/distance.py`, `app/dist_utils.py` и `nginx/redirects.map` остаются

#### Scenario: Бинарные и вендорные пути отфильтрованы

- **WHEN** дифф содержит бинарный файл или файл внутри `vendor/` либо `node_modules/`
- **THEN** эти файлы исключаются из результата фильтрации

#### Scenario: Миграции проходят фильтр

- **WHEN** дифф содержит миграцию `alembic/versions/0001_init.py` или `app/migrations/0002_users.py`
- **THEN** она остаётся в результате фильтрации: промпты ревью проверяют миграции

#### Scenario: Обычные исходники проходят фильтр

- **WHEN** дифф содержит обычные файлы исходного кода
- **THEN** они остаются в результате фильтрации с нетронутыми hunk'ами

## ADDED Requirements

### Requirement: Лимит размера изменения одного файла

Файл, текст hunk'ов которого в UTF-8 больше `DIFF_FILE_MAX_BYTES` байт (по умолчанию 1 048 576 — больше пакета контекста в восемь раз и больше `AST_MAX_FILE_BYTES`), SHALL отфильтровываться из ревью целиком; файл ровно на лимите SHALL проходить. Размер SHALL считаться без копии всего текста. Охват ревью SHALL относить к «отброшенным фильтром» те же файлы, что `filter_diff_files`.

#### Scenario: Изменение файла больше лимита отфильтровано

- **WHEN** текст hunk'ов одного файла больше `DIFF_FILE_MAX_BYTES` байт
- **THEN** файл исключается из результата фильтрации целиком, а остальные файлы PR остаются

#### Scenario: Файл на лимите проходит

- **WHEN** текст hunk'ов файла ровно `DIFF_FILE_MAX_BYTES` байт
- **THEN** файл остаётся в результате фильтрации

#### Scenario: Охват называет отфильтрованные файлы

- **WHEN** дифф содержит бандл или файл больше лимита
- **THEN** итоговый комментарий перечисляет его в группе «Отброшены фильтром»
