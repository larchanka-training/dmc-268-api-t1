# Spec Delta

## ADDED Requirements

### Requirement: Баланс текущего пользователя

`GET /api/v1/auth/me` SHALL отдавать `balance_eur`: баланс аккаунта текущего пользователя
(`review-billing`) точной десятичной строкой в евро, как стоимость прогона. У аккаунта без
зачислений и расходов баланс SHALL быть `"0"`.

#### Scenario: Баланс после зачисления

- **WHEN** пользователю зачислено 5 €, а его прогоны стоили 0.25 €
- **THEN** `balance_eur = "4.75"`

#### Scenario: Новый пользователь

- **WHEN** пользователь только что вошёл и ничего не зачислял
- **THEN** `balance_eur = "0"`
