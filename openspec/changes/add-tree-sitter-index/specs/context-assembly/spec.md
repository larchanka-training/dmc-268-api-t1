# Spec Delta: context-assembly

## Purpose

Дополняет сборку контекста прогона вторым источником уровня `ast`: сигнатурами
основной ветки из индекса определений (способность `definitions-index`).

## MODIFIED Requirements

### Requirement: Единый пакет контекста прогона

Воркер SHALL собирать для прогона пакет контекста, содержащий дифф по файлам,
AST-окружение изменённых строк и применимые правила владельца репозитория.
Дифф SHALL довыбираться через `VcsGateway` по паре `base_sha...head_sha` из
сообщения задачи, разбираться `parse_diff` и фильтроваться
`filter_diff_files`. Пакет MAY дополнительно содержать сигнатуры основной
ветки из индекса определений — второй источник уровня `ast` без отдельного
значения в `tiers` (требование «Сигнатуры основной ветки в AST-уровне»).
В `tiers` SHALL входить `diff`, а при наличии хотя бы одного AST-блока —
`ast`; `file_paths` SHALL перечислять файлы, дифф которых вошёл в пакет.

#### Scenario: Пакет содержит дифф, AST и правила

- **WHEN** дифф меняет метод класса в Python-файле, а в целевой ветке есть
  правило для этого файла
- **THEN** пакет содержит hunk'и файла, AST-окружение с классом и сигнатурой
  метода и это правило, а `tiers` равен `("diff", "ast")`

#### Scenario: Отфильтрованный файл не попадает в пакет

- **WHEN** дифф меняет `uv.lock` и `app/core.py`
- **THEN** в `file_paths` есть только `app/core.py`

## ADDED Requirements

### Requirement: Сигнатуры основной ветки в AST-уровне

При наличии индекса определений по ключу «репозиторий, base_sha» сборка
контекста SHALL включать в пакет сигнатуры из индекса как второй источник
уровня `ast`: определения файлов, разрешимых из импортов изменённых файлов.
Отдельного значения в `tiers` этот источник не получает.

#### Scenario: Сосед по импорту попадает в контекст

- **WHEN** изменённый файл импортирует модуль `app/domain/result`, которого
  нет в диффе, и индекс основной ветки содержит его определения
- **THEN** сигнатуры этого файла входят в пакет уровнем `ast`, а `file_paths`
  его не содержит

#### Scenario: Нерелевантные определения не попадают

- **WHEN** индекс содержит определения файлов, не входящих в дифф и не
  разрешимых из импортов изменённых файлов
- **THEN** эти определения в пакет не попадают

### Requirement: Дубль файла разрешается в пользу head

Записи индекса для файла, контур которого на `head_sha` вошёл в
AST-окружение, SHALL NOT добавляться в пакет: контур на `head_sha` побеждает
как более свежий.

#### Scenario: Изменённый файл не дублируется базовой версией

- **WHEN** файл изменён, его контур на `head_sha` вошёл в AST-окружение, а
  индекс содержит записи базовой версии того же файла
- **THEN** записи индекса для этого файла в пакет не добавляются

### Requirement: Бюджет записей индекса

Записи индекса SHALL заполнять бюджет токенов после AST-блоков изменённых
файлов; не поместившиеся SHALL перечисляться в `omitted` с указанием файла и
причины.

#### Scenario: Записи индекса вытесняются бюджетом

- **WHEN** после правил, hunk'ов и AST-блоков изменённых файлов остаток
  бюджета меньше объёма выбранных записей индекса
- **THEN** в пакет входит часть записей в порядке выбора, не поместившиеся
  перечислены в `omitted`

### Requirement: Промах индекса не меняет пакет

Промах или отсутствие индекса SHALL NOT менять состав остальных уровней
пакета: контекст собирается без записей индекса.

#### Scenario: Промах индекса не меняет пакет

- **WHEN** индекса по ключу «репозиторий, base_sha» нет или он вытеснен
- **THEN** пакет собирается без записей индекса, остальные уровни не меняются
