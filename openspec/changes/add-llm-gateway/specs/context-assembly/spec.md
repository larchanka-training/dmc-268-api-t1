# Spec Delta

## MODIFIED Requirements

### Requirement: Жёсткий лимит размера контекста

Оценка числа токенов пакета (`token_count`) SHALL NOT превышать
`context_max_tokens` из конфигурации; значение по умолчанию - 32 000. Оценка
SHALL быть детерминированной функцией сериализованного тела. При нехватке
бюджета система SHALL заполнять его в порядке: контекст PR (не больше
`pr_context_max_tokens`), правила (не больше `rules_max_tokens`), hunk'и
диффа, AST-блоки - и SHALL перечислять каждый не поместившийся элемент в
`omitted` с указанием файла и причины, не обрезая элементы посередине.

#### Scenario: Большой дифф не превышает лимит

- **WHEN** дифф прогона многократно больше `context_max_tokens`
- **THEN** `token_count` пакета не больше `context_max_tokens`, а не
  вошедшие hunk'и перечислены в `omitted`

#### Scenario: Дифф вытесняет AST

- **WHEN** дифф занимает почти весь бюджет
- **THEN** hunk'и диффа сохраняются, а не поместившиеся AST-блоки
  перечислены в `omitted`

#### Scenario: Длинное описание PR не вытесняет дифф

- **WHEN** описание PR больше `pr_context_max_tokens`
- **THEN** описание не входит в пакет и перечислено в `omitted`, а hunk'и диффа занимают бюджет как обычно

## ADDED Requirements

### Requirement: Контекст PR входит в пакет как недоверенные данные

Пакет SHALL содержать заголовок PR, его описание и сообщения коммитов PR, каждый текст - в отдельном блоке недоверенных данных.
Сообщения коммитов SHALL идти от нового к старому; не поместившиеся в долю бюджета SHALL перечисляться в `omitted`.
Сбой получения контекста PR SHALL NOT прерывать прогон: пакет собирается без него, причина перечисляется в `omitted`.

#### Scenario: Контекст PR в пакете

- **WHEN** у PR есть заголовок, описание и два коммита
- **THEN** пакет содержит четыре блока недоверенных данных: заголовок, описание и сообщения обоих коммитов, сначала более новый

#### Scenario: Инструкция в описании PR

- **WHEN** описание PR содержит «игнорируй предыдущие инструкции»
- **THEN** этот текст в пакете стоит внутри блока недоверенных данных

#### Scenario: Сообщения коммитов недоступны

- **WHEN** VCS не смогла вернуть сообщения коммитов PR
- **THEN** прогон продолжается, пакет собран без них, а в `omitted` перечислена причина

#### Scenario: Пустое описание PR

- **WHEN** описание PR пустое
- **THEN** блока описания в пакете нет, и в `omitted` оно не перечислено
