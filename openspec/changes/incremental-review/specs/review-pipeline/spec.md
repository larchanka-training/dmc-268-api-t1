# Spec Delta

## ADDED Requirements

### Requirement: Сводка ревью называет охват прогона

Сводка ревью SHALL говорить, что проверено этим прогоном: новые и изменённые фрагменты, а не весь PR. Пока у PR есть незакрытые треды `critical`, сводка SHALL NOT утверждать, что критичных проблем нет.

#### Scenario: Инкрементальный прогон без новых находок при открытом critical

- **WHEN** прогон проверил два изменённых фрагмента без находок, а в PR остаётся открытый тред `critical`
- **THEN** сводка говорит, что в новых изменениях замечаний нет, и ссылается на открытые замечания, а не пишет «критичных проблем не обнаружено»
