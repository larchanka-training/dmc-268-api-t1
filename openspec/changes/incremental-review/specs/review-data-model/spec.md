# Spec Delta

## ADDED Requirements

### Requirement: Журнал проверенных hunk'ов хранится по запросу на изменение

Система SHALL хранить для запроса на изменение записи журнала: путь, дайджест hunk'а, дайджест конфигурации, число вхождений, прогон, проверивший hunk, и время устаревания. Тройка «путь, дайджест hunk'а, дайджест конфигурации» SHALL быть уникальна в пределах запроса на изменение. Записи SHALL NOT удаляться неявно: устаревание SHALL отмечаться временем.

#### Scenario: Тот же hunk при другой конфигурации

- **WHEN** hunk с тем же содержимым проверен после смены дайджеста конфигурации
- **THEN** в журнале две записи с разными дайджестами конфигурации

#### Scenario: Hunk исчез из PR diff

- **WHEN** прогон получил PR diff без hunk'а, у которого есть запись
- **THEN** запись остаётся, у неё заполнено время устаревания

### Requirement: Прогон хранит причину отмены

Прогон `cancelled` SHALL хранить причину отмены — `superseded` (новый push) или `base_changed` (смена целевой ветки) — и ссылку на прогон, который его вытеснил.

#### Scenario: Вытесненный прогон

- **WHEN** прогон отменён, потому что в PR пришёл новый коммит
- **THEN** у прогона статус `cancelled`, причина `superseded` и ссылка на новый прогон
