# Spec Delta

## ADDED Requirements

### Requirement: Журнал проверенных hunk'ов хранится по запросу на изменение

Система SHALL хранить для запроса на изменение записи журнала: путь, дайджест hunk'а, дайджест конфигурации, признак перепроверки и прогон, проверивший hunk. Тройка «путь, дайджест hunk'а, дайджест конфигурации» SHALL быть уникальна в пределах запроса на изменение. Повторная запись hunk'а с тем же ключом SHALL обновлять запись, а не добавлять вторую. Записи SHALL удаляться только прогоном `completed` (`incremental-review`, «Исчезнувший hunk возвращает файл в область»).

#### Scenario: Тот же hunk при другой конфигурации

- **WHEN** hunk с тем же содержимым проверен после смены дайджеста конфигурации
- **THEN** в журнале две записи с разными дайджестами конфигурации

#### Scenario: Hunk проверен повторно

- **WHEN** hunk с записью снова проверен при той же конфигурации
- **THEN** запись та же, признак перепроверки и прогон обновлены, ошибки уникальности нет
