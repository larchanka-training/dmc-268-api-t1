## MODIFIED Requirements

### Requirement: Незарегистрированный репозиторий игнорируется

Вебхук для репозитория, которого нет в системе или у которого ревью выключено, SHALL получать HTTP 202 (ignored) без создания записей и без постановки задач. Регистрация или включение репозитория на лету по вебхуку SHALL NOT выполняться: это делает отдельная операция с авторизацией.

#### Scenario: Вебхук незарегистрированного репозитория не создаёт записей

- **WHEN** приходит валидный вебхук `pull_request.opened` для репозитория, не зарегистрированного в системе
- **THEN** ответ — HTTP 202 (ignored), записей не создаётся и задача не ставится

#### Scenario: Репозиторий не регистрируется автоматически

- **WHEN** валидный вебхук для незарегистрированного репозитория приходит повторно
- **THEN** репозиторий по-прежнему не зарегистрирован, а реакция системы не изменилась

#### Scenario: Вебхук выключенного репозитория

- **WHEN** приходит валидный вебхук `pull_request.opened` или `synchronize` для репозитория, у которого ревью выключено `DELETE /api/v1/repositories/{repository_id}`
- **THEN** ответ — HTTP 202 (ignored), как у незарегистрированного: прогон не создаётся, задача не ставится, репозиторий остаётся выключенным

## ADDED Requirements

### Requirement: Снятие приложения на GitHub выключает ревью

Вебхук с проверенной подписью `installation_repositories` с `action = removed` SHALL выключать ревью у репозиториев из `repositories_removed`; `installation` с `action` `deleted` или `suspend` — у подключённых репозиториев владельца установки (`installation.account.login`). Выключение SHALL быть тем же мягким, что у `DELETE /api/v1/repositories/{repository_id}`. Другие действия этих событий SHALL получать HTTP 202 (ignored) и ничего не включать.

#### Scenario: Репозиторий снят с установки

- **WHEN** приходит `installation_repositories` с `action = removed`, и в `repositories_removed` есть подключённый репозиторий
- **THEN** ответ — HTTP 202, у репозитория ревью выключено, прогоны и запросы на изменение на месте

#### Scenario: Установка удалена или приостановлена

- **WHEN** приходит `installation` с `action` `deleted` или `suspend` для установки на аккаунте `octo-org`
- **THEN** ответ — HTTP 202, у всех подключённых репозиториев `octo-org/*` ревью выключено

#### Scenario: Приложение вернули

- **WHEN** приходит `installation` с `action = unsuspend` или `installation_repositories` с `action = added`
- **THEN** ответ — HTTP 202 (ignored), выключенные репозитории остаются выключенными

#### Scenario: Подпись не прошла

- **WHEN** вебхук `installation` или `installation_repositories` приходит без подписи или с неверной подписью
- **THEN** ответ — HTTP 401, ревью ни у одного репозитория не меняется
