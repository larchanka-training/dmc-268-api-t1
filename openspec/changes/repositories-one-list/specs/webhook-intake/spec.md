## MODIFIED Requirements

### Requirement: Незарегистрированный репозиторий игнорируется

Вебхук `pull_request` для репозитория, которого нет в системе или у которого ревью выключено, SHALL получать HTTP 202 (ignored) без создания записей и без постановки задач. У выключенного SHALL ставиться на head проверка `dmc-268-ai-review` `success` «Ревью выключено в сервисе» (best-effort), у незарегистрированного — ничего. Вебхук `pull_request_review_thread` выключенного репозитория SHALL записывать состояние треда, как у включённого, а на head SHALL ставить ту же проверку выключенного вместо пересчёта по тредам. Регистрация или включение репозитория на лету по вебхуку SHALL NOT выполняться: это делает отдельная операция с авторизацией.

#### Scenario: Вебхук незарегистрированного репозитория не создаёт записей

- **WHEN** приходит валидный вебхук `pull_request.opened` для репозитория, не зарегистрированного в системе
- **THEN** ответ — HTTP 202 (ignored), записей не создаётся и задача не ставится

#### Scenario: Репозиторий не регистрируется автоматически

- **WHEN** валидный вебхук для незарегистрированного репозитория приходит повторно
- **THEN** репозиторий по-прежнему не зарегистрирован, а реакция системы не изменилась

#### Scenario: Вебхук выключенного репозитория

- **WHEN** приходит валидный вебхук `pull_request.opened` или `synchronize` для репозитория, у которого ревью выключено `DELETE /api/v1/repositories/{repository_id}`
- **THEN** ответ — HTTP 202 (ignored), как у незарегистрированного: прогон не создаётся, задача не ставится, репозиторий остаётся выключенным

#### Scenario: Выключенный репозиторий: проверка success «Ревью выключено в сервисе»

- **WHEN** приходит `pull_request.opened` или `synchronize` для выключенного репозитория, а в ruleset `dmc-268-ai-review` — обязательная проверка
- **THEN** на `head_sha` токеном установки ставится check run `dmc-268-ai-review` с `conclusion=success` и заголовком «Ревью выключено в сервисе», и PR не ждёт проверку; если GitHub не ответил — ответ всё равно HTTP 202 (ignored), сбой пишется в лог, доставка не переотправляется

#### Scenario: Незарегистрированный репозиторий: проверки нет

- **WHEN** приходит `pull_request.opened` для репозитория, которого нет в системе
- **THEN** к GitHub запроса нет, check run не ставится

#### Scenario: Тред ревью у выключенного репозитория

- **WHEN** у репозитория, выключенного `DELETE /api/v1/repositories/{repository_id}`, человек закрывает на GitHub тред замечания бота и приходит `pull_request_review_thread` с `action=resolved`
- **THEN** ответ — HTTP 202 (acknowledged), у записи `published_comments` выставляется `thread_resolved=true`, а на head PR ставится проверка выключенного `success` «Ревью выключено в сервисе», даже если другой `critical` тред открыт; прогон не создаётся, задача не ставится
