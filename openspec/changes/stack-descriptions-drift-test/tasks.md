## Примечания к выполнению

**2.2 проверена синтетически, а не правкой реальных файлов.** Функциям сверки скормлено настоящее содержимое обоих дефектов до их исправления. Результат: расхождение точки монтирования — краснеет, отсутствие ресурса миграций — краснеет, расхождение мажорной версии — краснеет. Отдельно проверена полумера: ресурс миграций есть, но `api` от него не зависит — тоже краснеет, потому что API в этом случае стартует параллельно с миграциями, то есть ровно как до фикса.

Правка реальных файлов ради проверки отвергнута сознательно: она деterминирована хуже и оставляет шанс забыть вернуть обратно.
