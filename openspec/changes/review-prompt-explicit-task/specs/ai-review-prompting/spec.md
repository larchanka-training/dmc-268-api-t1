## ADDED Requirements

### Requirement: Явная задача ревью

Системный промпт SHALL ставить задачу: проверить каждую добавленную и изменённую строку и вернуть все проблемы, внесённые PR, проходя каждую категорию порядка анализа для каждого файла. Замечание SHALL называть вход или состояние, при котором код ломается. Пустой список замечаний SHALL допускаться только как итог прохода, а не по умолчанию.

#### Scenario: Несколько дефектов разных классов

- **WHEN** изменение содержит дефекты безопасности, корректности и производительности
- **THEN** ревью возвращает замечание по каждому, а не только по первому найденному

#### Scenario: Проблем нет

- **WHEN** после прохода по всем категориям проблем не найдено
- **THEN** ревью возвращает пустой список замечаний, не придумывая находок
